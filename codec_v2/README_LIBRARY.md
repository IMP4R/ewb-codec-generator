# Библиотека программного построения настоящих EWB 5 схем

Не SPICE-импорт и не изображения. Генерация схем не использует клики мышью.

## Модули
- `codec.py`: контейнер EWB, PKWARE DCL, транспорт и контрольная сумма; unpack/explode/encode_ewb.
- `schematic.py`: секции документа и аналоговые компоненты.
- `network.py`: проверенные координаты выводов, ортогональные маршруты, запрет повторного подключения терминала, экспорт topology.json.
- `digital.py`, `digital_network.py`: штатные DIGITAL-вентили, индикаторы и координаты контактов.
- `logic_builder.py`: сборка комбинационной логики, размещение по слоям и каналы разветвления.
- `build_combinational.py`, `build_sumsub.py`: генераторы лабы 4.
- `build_memory_latches.py`: RS, синхронный RS, синхронный D из простых вентилей, без готовых триггеров.
- `prepare_lab5.py`: комплект лабы 5. Register/Memory копируются из методички байт-в-байт; самодельный регистр удаляется из сдачи и архивируется.

## Минимальный пример
```python
from digital_network import DigitalNetwork
n = DigitalNetwork()
a = n.addgate('Not', 1000, 900, 'G1', 'NOT')
b = n.addgate('ProbeR', 1250, 900, 'OUT', 'Q', orientation=2)
n.connect(a, 1, b, 0, 'Q')
n.emit('example.ewb', zoom=80)
```
Вход в примере не подключён: это пример API, не законченная схема.

## Повторная сборка лабы 5

```sh
cd /Users/user0/ewb_rev/codec_v2

```

## Границы проверки
Экспорт/roundtrip и проверки topology.json не заменяют реальное исполнение EWB. GUI используется для открытия, запуска, переключения входов и снятия настоящих скриншотов. Автоматическая разводка пока не гарантирует отсутствие наложений подписей: визуальная приёмка обязательна.

Исходные Register.ewb и Memory.ewb не переразводятся. Отдельная teacher_view копия нормализует только настройки окна/сетки; Elements и Wires проверяются на идентичность. Она не заменяет оригинал в сдаче.
