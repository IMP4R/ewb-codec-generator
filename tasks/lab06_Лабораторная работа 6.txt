1. Команда MOV. Пересылка 8- и 16-разрядных данных 
 
Реализуем на Ассемблере простейшую программу присваивания целочисленных данных 
длиной 8 и 16 бит. Пусть данное длиной 8 бит будет беззнаковое, а 16 бит – знаковое. 
Ввод и вывод информации сделаем в среде Visual C++. Программа на C++ будет главной, 
из неё мы будем вызывать модуль на Ассемблере. 
 
1. Создайте в Visual Studio проект консольного приложения (File – New – Project... – Vis-
ual C++ – Win32 Console Application). При создании проекта в Мастере выберите 
пункт «Пустой проект». 
Назовите проект, например, Mov16. 
 
2. Добавьте в папку исходного кода проекта новый файл CPP, назовите его, например, 
mov16.cpp. 
Скопируйте в этот файл следующий код: 
 
Программа на C++ (mov16.cpp): 
 
// Подключаем заголовочные файлы 
#include <stdio.h> 
#include <conio.h> 
 
// Объявляем внешние функции и переменные 
extern "C" void mov_16(void); 
extern "C" short int a, x; 
extern "C" unsigned char b, z; 
 
// Основная функция 
void main() 
{ 
 
printf("Calculate: x = a; a, x : short int;\n"); 
 
printf("Enter a: "); 
 
scanf_s("%d",&a); 
 
x = a;

printf("Enter b: "); 
 
scanf_s("%d",&b);

x = 0; z = 0;

Комментарий: 
В этой программе объявлены 4 переменные: две – знаковые, двухбайтовые (short 
int a, x), две – беззнаковые, однобайтовые (unsigned char b, z). 
 
extern – спецификатор, указывающий компилятору, что переменная определяется в 
другом месте программы (в другом файле или дальше по тексту). Строковая констан-
та "C" сообщает о способе именования переменных и функций – в стиле Си, т. е. пе-
ред каждым именем будет записываться символ подчеркивания ( _ ). 
 
3. В папке с файлом mov16.cpp создайте текстовый файл и назовите его mov_16.asm. 
 
4. Откройте файл mov_16.asm в Visual Studio или в любом текстовом редакторе и ско-
пируйте в него следующий код на Ассемблере:

PUBLIC mov_16 
;функция, доступная для внешних модулей

;определение функции 
 
MOV AX,a

Комментарий: 
• .MODEL FLAT,C – указание о согласовании имен «С» генерирует у имен всех пе-
ременных и функций знак подчеркивания (_). 
• PUBLIC имя1, имя2,… 
Директива PUBLIC указывает компилятору и компоновщику, что данные имя1, 
имя2,… должны быть доступны для других программ. Имена могут быть метка-
ми, переменными или именами подпрограмм. 
 
5. Создайте объектный файл mov_16.obj на основе файла mov_16.asm с помощью ас-
семблера MASM – ML.exe. 
Для этого скопируйте в папку с файлом mov_16.asm файл ассемблера ML.exe. 
Откройте командную строку для текущей папки: 
• Пуск – Выполнить – cmd 
• В командной строке ввести команду: cd Полный путь к папке. 
 
Для создания объектного файла в командной строке введите команду: ML.exe /c 
/coff mov_16.asm 
 
В объектном файле хранится машинный код, сгенерированный по ASM-файлу и ин-
формация об экспортируемых переменных и функциях (a, b, x, z, mov_16). 
 
6. Чтобы проект в Visual Studio нашел объектный файл mov_16.obj, нужно указать путь

Если объектный файл находится не в той же папке, что и файл CPP, требуется указать 
полный путь, например “c:\masm\bin\mov_16.obj”.

2. Пересылка 32-разрядных данных 
 
Решим более сложную задачу: переслать информацию из переменной А длиной 32 бита в 
переменную В с использованием 16-разрядных регистров. Чтобы удобно было наблю-
дать и делать выводы, занесем в переменную A какое-нибудь определенное число, 
например 12345678h. 
 
Модуль на ассемблере (mov_32.asm):

.586P 
 
;Плоская модель памяти, соглашение о вызовах в стиле С
