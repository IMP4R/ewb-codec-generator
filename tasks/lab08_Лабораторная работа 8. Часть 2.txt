Лабораторная работа 8. Часть 2 
Циклы 
Цель работы 
Научится оперировать с циклами для данных в формате short int. Исходные 
данные и результат должны быть проверены на диапазон допустимых 
значений. 
Порядок работы 
1. Найти свой вариант в каждом из блоков заданий А, В и С. 
2. Написать модули вычисления задания на языке Ассемблера. 
3. Написать на С++ программу корректного ввода исходных данных (с 
контролем допустимого диапазона), вычисления задания и вывода 
полученного результата. 
4. Встроить вызов ассемблерного модуля в программу на С++. 
5. Произвести тестовые проверки. 
Задания А: использовать одномерный статический массив. 
1. Подсчитайте среднее арифметическое всех положительных элементов 
массива. 
2. Подсчитайте количество четных элементов массива, стоящих на 
нечетных позициях. 
3. Выведите на экран номера всех элементов, попадающих в диапазон 
[A..B] (целые числа A и B вводятся с клавиатуры). 
4. Выведите на экран значение максимального элемента и их количество. 
5. Замените все минимальные элементы нулями. 
6. Подсчитайте среднее арифметическое всех неотрицательных элементов 
массива. 
7. Найдите количество пар соседних элементов, сумма которых равна 
заданному числу. 
8. Выведите на экран значение минимального элемента и их количество.

9. Подсчитайте количество нечетных элементов массива, стоящих на 
четных позициях. 
10. Замените все максимальные элементы единицами. 
Задания В: использовать двумерный статический массив. 
1. Реализовать подсчет суммы двух двумерных массивов. 
2. Найдите сумму положительных элементов массива. Если все элементы 
неотрицательные, выведите сообщение об этом. 
3. Измените знак у максимального по модулю элемента массива. Если 
таких элементов несколько, то поменяйте знак у каждого из них. 
4. Реализовать подсчет разности двух двумерных массивов. 
5. Поменяйте местами максимальный и минимальный элементы всего 
массива. 
6. Определите, есть ли в массиве элемент, равный заданному числу. Если 
есть, то выведите номер одного из таких элементов. 
7. Найдите сумму неотрицательных элементов массива. Если все 
элементы положительные, выведите сообщение об этом. 
8. Измените знак у минимального по модулю элемента массива. Если 
таких элементов несколько, то поменяйте знак у каждого из них. 
9. Замените максимальный элемент (элементы) массива нулем. 
10. Выведите на экран номера всех элементов, попадающих в диапазон 
[A..B] (целые числа A и B вводятся с клавиатуры). 
Задания С: решить задачи из блока В, используя двумерный динамический 
массив.
